# Vanishing Gradients

A 6-layer sigmoid network and a 6-layer ReLU network can have the same
shapes and still train completely differently. The difference is what
happens to the gradient as it's chained back through each layer's
activation derivative.

Implement in `solution.py`:

```python
def sigmoid(x):
    """1 / (1 + exp(-x)), elementwise. Must not overflow for large |x|."""

def sigmoid_grad(x):
    """d/dx sigmoid(x) = sigmoid(x) * (1 - sigmoid(x))."""

def relu_grad(x):
    """d/dx relu(x): 1 where x > 0, else 0."""

def backprop_gradient_norm(grad_fn, pre_activations, upstream_grad=1.0):
    """Chain an upstream scalar gradient back through a stack of layers.

    pre_activations: a 1D array, one pre-activation value per layer, in
    forward order (pre_activations[0] is the first layer, [-1] the last).
    Backprop runs in reverse: starting from upstream_grad, multiply by
    grad_fn(pre_activations[-1]), then grad_fn(pre_activations[-2]), and
    so on back to pre_activations[0]. Return the final scalar gradient
    that reaches the input.
    """
```

Rules the tests check:

- `sigmoid_grad`'s maximum value is exactly `0.25`, at `x = 0` - it can
  never exceed that, no matter the input.
- `relu_grad` is exactly `1` for positive inputs and `0` for negative ones.
- Chaining `sigmoid_grad` back through several layers whose pre-activations
  sit away from 0 shrinks the gradient toward zero geometrically (each
  layer multiplies by something `<= 0.25`) - by 6 layers it should be tiny.
- Chaining `relu_grad` back through the same depth, with all pre-activations
  positive, leaves the gradient exactly unchanged - each layer multiplies
  by `1`.
