# L2 Regularization

A big network trained on a small dataset can memorize it: near-perfect
training accuracy, much worse test accuracy. L2 regularization discourages
that by penalizing large weights directly in the loss.

Implement in `solution.py`:

```python
def l2_penalty(w, factor):
    """factor * sum(w ** 2) over all elements of w."""

def regularized_loss(base_loss, w, factor):
    """base_loss + l2_penalty(w, factor)."""

def l2_gradient(w, factor):
    """Gradient of l2_penalty with respect to w: 2 * factor * w, elementwise.

    This is what actually gets added to a weight's gradient during
    training -- it's why L2 is also called "weight decay": every update
    nudges each weight a little toward zero, in proportion to its own
    size.
    """
```

`w` may be any shape (a vector or a matrix) - the penalty and its gradient
must work elementwise/over the whole array either way.

Rules the tests check:

- `l2_penalty(w, 0.0)` is always `0.0`, regardless of `w`.
- `l2_penalty` scales with `factor` and with the *square* of the weights -
  doubling every weight should roughly quadruple the penalty (before
  scaling by `factor`).
- `regularized_loss` is strictly `base_loss + l2_penalty(...)` - nothing
  else folded in.
- `l2_gradient(w, factor)` has the same shape as `w`, and for `w=0` is
  exactly `0` (regularization has nothing to shrink there).
