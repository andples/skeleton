# NumPy Tensor Manipulation Drills — Purpose & Mechanics

This drill set is a hands-on tensor-manipulation bootcamp. Its purpose is to build the reflexive fluency with array shapes, broadcasting, reductions, and matrix multiplication that underpins virtually every neural network implementation you'll write, from a basic MLP to multi-head attention.

## What the Exercise Builds Overall

Deep learning code is, underneath the abstractions, just a sequence of shape transformations and linear algebra operations. If you can't instantly reason about "what shape comes out of this operation and why," you'll spend most of your debugging time chasing shape-mismatch errors instead of understanding your model.

This drill set forces you to internalize five layers of that skill, each building on the last:

1. Reshaping data into the layouts frameworks expect
2. Collapsing dimensions correctly during pooling and normalization
3. Executing matrix products (including batched ones used in attention)
4. Computing geometric similarity via normalization
5. Combining all of the above into real components like layer norm and pairwise distances — both used constantly in transformers and metric-learning systems

## Level 1: Reshaping and Axis Reordering

These five drills teach you that a tensor's underlying data buffer is often just a flat sequence of numbers, and shape is a *view* into that buffer.

- **Flatten (01)** and **spatial partition (02)** are inverses of each other: `reshape(-1)` collapses everything into one axis by inferring size from total element count, while reshaping into `(batch, steps, features)` shows that row-major (C-order) memory layout determines which elements land in which output positions — this is why `res[0,1,2]` in the test resolves to a specific value (5), not an arbitrary one.
- **Expand/squeeze (03)** teaches that adding or removing a size-1 axis (`np.expand_dims` / `np.squeeze`) doesn't move any data — it just changes how existing data is indexed. This matters constantly when you need to align shapes for broadcasting.
- **Channels-first transpose (04)** and **matrix transpose (05)** distinguish reshape from transpose: reshape reinterprets the flat buffer without moving values, while `np.transpose`/`.T` actually permutes axis order, physically reordering which values sit where in the result. Confusing these two is one of the most common shape bugs in image and video pipelines (channels-last vs. channels-first conventions).

## Level 2: Reductions Across Axes

Every pooling, normalization, and aggregation operation in ML is a reduction — collapsing one or more axes down to a summary statistic.

- **Row/column means (06)** teaches the `axis` argument directly: `axis=0` collapses rows (producing per-column stats), `axis=1` collapses columns (per-row stats) — the axis you specify is the one that *disappears*.
- **Temporal pooling (07)** and **global average pooling (08)** apply this to real architectures: averaging over time steps (RNN/Transformer outputs) or over both spatial axes at once (CNN feature maps) to compress a sequence or image into a fixed-size vector per sample.
- **Feature centering (09)** and **max-with-keepdims (10)** teach `keepdims=True`, which retains the reduced axis as size 1 instead of dropping it, so the result broadcasts cleanly back against the original tensor — essential for centering data or subtracting a max value from logits (e.g., for numerically stable softmax) without a manual reshape.

## Level 3: Matrix Multiplication Mechanics

This level is the mathematical core of neural networks — nearly every layer boils down to matrix multiplication.

- **Linear layer (11)** is the literal computation inside every dense/fully-connected layer: `Y = X @ W + b`, where matmul mixes input features into `W`'s output dimension and `b` is added via broadcasting.
- **Matmul with implicit transpose (12)** teaches that you rarely need to materialize a transposed copy of a matrix — you can compute `A @ B.T` directly, which matters for performance at scale.
- **Batched matmul (13)** and **attention scores (14)** extend this to tensors with leading "batch" axes: NumPy's `@` operator (and `np.matmul`) treats all but the last two axes as batch dimensions and performs independent matrix multiplications within each batch slice. This is exactly the mechanism transformers use to compute `Q @ K^T` per attention head, producing an `(SeqLen, SeqLen)` score matrix for every batch and head simultaneously.
- **Batched outer product (15)** shows how to construct a *rank-increasing* operation (outer product, `D → D×D`) from matmul, by inserting singleton axes with `expand_dims` so that `(B, D, 1) @ (B, 1, D)` broadcasts into `(B, D, D)` — a pattern that reappears in attention-weighted value aggregation and covariance computation.

## Level 4: L2 Normalization and Geometry

These drills connect linear algebra to *geometric meaning* — vector length and angle — which underlies embeddings and similarity search.

- **Normalizing embeddings (16)** and **per-pixel vector normalization (17)** both divide a vector by its own L2 norm along a chosen axis, projecting it onto the unit hypersphere. This is standard practice before comparing embeddings (e.g., face recognition, retrieval systems) because it makes dot products directly equivalent to cosine similarity.
- **Cosine similarity matrix (18)** combines normalization with matmul: normalize both matrices row-wise to unit vectors, then a single matrix multiplication (`A_norm @ B_norm.T`) yields *every pairwise* cosine similarity at once — the same operation search engines and recommender systems use to rank nearest neighbors in embedding space.

## Level 5: Synthesis (LayerNorm and Distance Matrices)

The final two drills combine everything above into components you'll recognize from real model code.

- **Manual layer normalization (19)** implements the exact operation inside every Transformer block: compute mean and standard deviation over the last axis (with `keepdims`), then rescale so each feature vector has zero mean and unit variance — stabilizing training by preventing activations from drifting to extreme magnitudes.
- **Pairwise squared distance (20)** teaches a classic algebraic trick: rather than looping over every pair of points, it expands \( \|x-y\|^2 = \|x\|^2 + \|y\|^2 - 2(x \cdot y) \), computing the cross term with a single matmul and the norm terms with `reduce_sum`, then combining them via broadcasting. This vectorized identity is exactly how efficient k-nearest-neighbor and clustering algorithms (like k-means) compute distance matrices at scale without any explicit loop.

## Takeaway

Taken together, completing all 20 drills leaves you able to read or write almost any tensor-shape line in a modern ML codebase — from a basic dense layer to the inner workings of multi-head attention — by reasoning directly from shapes and broadcasting rules rather than trial and error.
