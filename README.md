# Koredl Skeleton

This is your personal Koredl workspace. It's a fork of `koredl/skeleton` —
everything you work on lives here, in one repo, forever.

- `problems/<slug>/` — a Problems-bank item you fetched via "Koredl: Solve Problem".
- `worlds/<world_slug>/levels/<level_slug>/quests/<quest_slug>/` — a Quest you
  fetched via "Koredl: Browse Quest".

Don't delete `.koredl.json` inside a folder — the extension uses it to know
which problem/quest the file you're editing belongs to when you press
Run/Submit.
